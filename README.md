# Degree Verification Portal

A production-ready Degree Verification Portal built with:

- Node.js
- Express.js
- MySQL
- HTML5
- CSS3
- Vanilla JavaScript

## Installation

```bash
git clone <repository>
cd degree-verification-portal
npm install
```

Create a `.env` file:

```bash
cp .env.example .env
```

Edit the database credentials.

Start development:

```bash
npm run dev
```

Production:

```bash
npm start
```
